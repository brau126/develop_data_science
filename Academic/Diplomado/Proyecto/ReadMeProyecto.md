# Proyecto General de Diplomado Ciencia de Datos

Este proyecto se realiza principalmente en una computadora local, peor por trasalado se cargan los avances en dicho repositorio para mantener un control de cambios y hacer posible acceder a él y modificarlo desde algún equipo diferente.

## Datos

Los datos son principalmente recuperados de diversas locaciones públicas y otra información es obtenida a por un web scrapping. Para reprudicibilidad se añade el link de la carpeta de Drive con las Bases a utilizar para poder tener acceso a ellas desde cualquier locación; una vez que se tenga una base de datos incial y completa se añadira a este repositorio para una mejor reproducibilidad.
